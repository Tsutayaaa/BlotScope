# WB Marker v0.4.0 — Responsive Panels & PageRuler Presets

- Responsive English/Chinese analysis panels without horizontal scrolling.
- Advanced settings and calibration diagnostics collapsed by default.
- Compact band results with expandable full details.
- Named PageRuler Plus (10–250 kDa) and PageRuler (10–180 kDa) presets.
- Product-specific reference colors in the preset preview, marker table, profile, and image annotations; colors stay associated with each marker group.
- Existing custom presets, numerical estimation, and full exports retained.

Download `WB-Marker-v0.4.0-macOS-arm64.zip`, extract it, quit the old app, and replace `WB Marker.app` in Applications. Apple Silicon macOS only; Python is not required. This build is not Developer ID signed or Apple notarized.

Validation: 24 regression tests, including real Tk layouts in English and Chinese at 820×560, 1180×760, and 1440×900. Clean-machine testing and real experimental image acceptance remain separate checks.
