# BlotScope v1.0.1 — Project Rename

WB Marker is now **BlotScope**.

This release updates the application name, window title, Python package, launcher, app bundle identifier, documentation, repository links, and installation archive. The logo and analysis behavior are unchanged. No new analytical features or calculation changes are included.

## Install or update

Download **BlotScope-v1.0.1-macOS-arm64.zip**, extract it, and move **BlotScope.app** into Applications. Quit the old WB Marker app before switching. You may remove the old app after confirming BlotScope works.

Existing language preferences and custom marker presets are copied from the legacy configuration directory on first launch when the new directory does not exist. Historical Python imports and source launchers remain compatible.

Apple Silicon macOS only. Python is not required. This app is not Developer ID signed or Apple notarized.
